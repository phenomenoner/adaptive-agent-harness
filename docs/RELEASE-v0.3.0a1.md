# Adaptive Agent Harness v0.3.0a1 — Source-Parity Maintenance Alpha

**The same bounded runtime contract, now with the complete verified source.**

This maintenance prerelease synchronizes the public executable tree with the final standalone
AR-LT3 source, gives those bytes a new immutable version, and closes a compensation deadline-admission
gap found after the first public alpha. It does not rewrite `v0.3.0a0`, upgrade an installed host,
or expand AAR authority.

## What changed

- compensation authority is rechecked after waiting for the SQLite write reservation;
- the effective deadline is checked again after durable intent commit, immediately before provider
  invocation;
- expiry in either admission window produces zero provider calls;
- two regressions cover the lock-wait and post-commit windows;
- current-state projections now record the complete schema-v5 boundary and sanitized
  runtime/dispatcher generation `13 / 13` readback;
- package-bound schema, MCP, host-profile, Codex cachebuster, and operation-skill metadata are refreshed
  under `0.3.0a1`;
- all 17 localized README files point to the current tag and public verification count.

## Verification

The public source candidate reproduced:

- **249 passed, 1 platform-gated skip** in the full repository suite;
- Python 3.11 through 3.14 package support;
- the 30-tool MCP v7 surface;
- generated contract, MCP, and host-profile assets matching executable source;
- deadline-admission regressions with zero provider invocation after expiry;
- additive schema v5, new-generation workspace restore, broker receipt reconciliation, process-loss,

Release gates also include public-source hygiene, Ruff, exact-wheel build and isolated install,
fresh-clone readback, and remote tag/release verification.

## Important alpha boundaries

- This is not a security sandbox.
- RLM jobs and IPython workspaces are sibling surfaces; they do not share state or execute inside one
  another automatically.
- The runtime does not own provider credentials, generic external-effect execution, activation, or
  final delivery.
- It does not promise universal exactly-once semantics.
- Managed AHC admission, multi-tenant isolation, and stable API compatibility remain outside this
  release.
- Package-index publication is not promised; install from the pinned Git tag above.

This GitHub release publishes source archives generated by GitHub. No standalone wheel is attached;
the installed private-host cutover artifact and this public source prerelease are distinct artifacts.
