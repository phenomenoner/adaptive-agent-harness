# AHC integration boundary

`rlm-contract-v1.json` is generated by `aar-contract`; it binds an AHC consumer to the same
transport-neutral AAR capability, grant, request-envelope, RLM, budget, operation-certainty, and
terminal-receipt semantics used by the reference host.

This directory is not an AHC adapter implementation. An AHC-native adapter may strengthen exact
session binding, retained-child lifecycle, cancellation propagation, and restart reconciliation,
but it must preserve the generated contract and keep provider credentials, direct effect
execution, and final delivery outside the AAR kernel.

CodeGraph remains an optional external workflow over resolved artifact bytes. NOOA remains design
input only; neither is an AHC or AAR runtime dependency.
